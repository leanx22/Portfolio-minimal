Algunos de mis proyectos

  • NexusShop

    Código abierto

    Ecommerce REST API.

    API REST desarrollada con Java y Spring Boot. Imita una plataforma de ecommerce con CRUD completo para productos, búsqueda y autenticación. Utiliza Hibernate junto con PostgreSQL para persistencia, Spring Security para acceso por roles y autenticación mediante JWT.

    Ver en GitHub |

  • Aperture restaurante

    Código abierto

    Gestor de negocio.

    Proyecto full stack propuesto como trabajo integrador final en la universidad. Una aplicación para dispositivos android completa para gestionar las diferentes áreas de un restaurante. Incluye autenticación por roles, notificaciones push, chat en tiempo real, juegos, herramientas para gestión y más. Se utilizó Angular, Ionic y supabase.

    Ver en GitHub |

  • Barber House

    Código privado

    Gestor de negocio.

    Proyecto full stack propuesto como solución a los problemas de organización de una peluquería de barrio. Enfocada en dispositivos android, permite la autogestión de turnos en el establecimiento ahorrando tiempo al personal. Incluye notificaciones push, herramientas para gestión, panel de administrador, CRUD completo de servicios y listado de trabajos por completar. Se utilizó Angular, Ionic y supabase.

    Visitar repositorio

  • Carpeta Médica

    Código privado

    Gestor de estudios médicos.

    Proyecto Android Java. La aplicación soluciona el desorden de estudios médicos digitales de diferentes clínicas, unificándolos todos en un mismo lugar, de forma local, organizada y segura. Permite el guardado de estudios médicos en diferentes formatos, creación de diferentes perfiles de usuario, exportación e importación de perfiles mediante archivos ZIP o WiFi desde otro dispositivo. Incluye funcionalidades como listado, búsqueda y facilidad de compartir los estudios de forma simple para usuarios de diferentes edades. Actualmente se encuentra en etapa de pruebas públicas en PlayStore.

    Ver en PlayStore

  • WallSwitch

    Código abierto

    Selector de fondos de escritorio para noctalia-shell.

    Proyecto personal para probar las capacidades de Antigravity CLI. WallSwitch permite el cambio de fondos de escritorio en vivo en entornos linux con noctalia-shell. Otorga la capacidad de personalizarlo por completo, agregando módulos (como texto, hora, espectro de audio) creados por la comunidad o el usuario, además de seguir la paleta de colores del sistema en caliente.

    Visitar repositorio
